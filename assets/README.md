# Assets

All artwork belongs to the CHIZ brand and comes from the booth project.

- `chiz-logo.png`, `chiz-wordmark.png`, `chiz-slogan.png` — brand marks
- `poster-1.jpg` — brand poster used in the hero
- `recycle.png`, `broken-skate.png` — white pictograms for dark surfaces
- `products/*.png` — the six booth product photos (pixel art, 160×160)
- `favicon.png`, `apple-touch-icon.png` — generated from the logo

Fonts:

- **Lalezar** — titles, brand, prices, main buttons (OFL, see `Lalezar-OFL.txt`)
- **Vazirmatn** — body text (OFL, https://github.com/rastikerdar/vazirmatn)

The kiosk's Sina Bold (`SSINABD.TTF`) is copyrighted and is **not** included;
Lalezar is its licensed fallback.
