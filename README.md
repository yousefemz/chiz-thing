# چیز — CHIZ_THING

ویترین تک‌صفحه‌ای برند **«چیز»**؛ ابزار سرگرمی دستی که از تخته‌اسکیت‌های شکسته ساخته می‌شود.

سایت با همان زبان بصری باجه‌ی فروش چیز («کمیک قورمه») طراحی شده است: زمینه‌ی سرمه‌ای،
قاب قرمز، کارت‌های کاغذی با خط مرکب و سایه‌ی سخت، برچسب زرد قیمت و فونت لاله‌زار.

## دیدن سایت

نسخه‌ی منتشرشده: **https://yousefemz.github.io/chiz-thing/**

برای اجرای محلی کافی است یک سرور ساده بالا بیاورید:

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## چه چیزی دارد؟

- یک صفحه، بدون بیلد و بدون وابستگی — فقط HTML، CSS و JS
- ویترین ۶ محصول با عکس، قیمت و موجودی
- سبد خرید سبک با ذخیره در `localStorage`
- ثبت سفارش در دایرکت اینستاگرام (`@CHIZ_THING`) با متن سفارش کپی‌شده
- راست‌به‌چپ، فونت‌های خودمیزبان، ریسپانسیو و سازگار با `prefers-reduced-motion`

## ساختار

```
index.html            صفحه‌ی کامل سایت
assets/css/styles.css تم «کمیک قورمه»
assets/js/app.js      سبد خرید، مودال، انیمیشن‌های ورود
assets/fonts/         لاله‌زار + وزیرمتن (OFL)
assets/img/           لوگو، پوستر و عکس محصولات
```

## استایل

پالت و اندازه‌ها از `kiosk/theme.py` پروژه‌ی باجه گرفته شده‌اند:

| توکن | مقدار | کاربرد |
|---|---|---|
| `ink` | `#2e2e33` | خط دور، سایه، متن |
| `stage` | `#244085` | زمینه‌ی سرمه‌ای |
| `danger` | `#ec1f24` | قاب قرمز، اکشن خطر |
| `hi` | `#fff100` | زرد برند، دکمه‌ی اصلی |
| `alt` | `#7b3e95` | بنفش، نشانگرها |
| `orange` | `#f7931e` | نشان تعداد |
| `paper` | `#ffffff` | کارت‌های کاغذی |

قاعده‌ها: خط مرکب ۳ پیکسل + سایه‌ی سخت بدون بلور، گوشه‌های ۱۰–۱۶ پیکسل،
متن روی کاغذ همیشه مرکب، متن سفید فقط روی قرمز/بنفش، لاله‌زار فقط برای تیتر،
برند، قیمت و دکمه‌ی اصلی.
